# claude-mem for Grok Bot

Install from the Grok Bot or Cursor plugin store as **claude-mem-grok-bot**. Does not install Cursor.

Grok Bot has no hooks. After install: `npx github:JonathanWorks/claude-mem#pwm install --ide grok-bot --provider openrouter` for a local worker with your own OpenRouter key. `--provider host` is an explicit local loopback-shim opt-in. Set `CLAUDE_MEM_MCP_TOKEN` for remote MCP.
